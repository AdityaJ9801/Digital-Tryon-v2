# Auto-derivation of pose + clothing-agnostic image (tryondiffusion/preprocessing.py)
# Pinned to 0.10.14, the last version with the legacy `solutions.pose` API.
# mediapipe>=1.0 (and some 0.10.x releases after 0.10.14) dropped `solutions`
# in favor of the Tasks API, whose native library unconditionally links
# against libEGL/libGL even for CPU-only inference - a hard native-dependency
# requiring root/apt access, which headless GPU servers/containers commonly
# don't have. `solutions.pose` runs a pure CPU graph with no such dependency.
# tryondiffusion/preprocessing.py auto-detects and uses whichever API the
# installed mediapipe version exposes, so a newer version still works fine
# on a machine that does have libEGL/libGL available.
mediapipe==0.10.14
# Required by default: TryOnConfig.agnostic_method defaults to "segmentation" -
# a real pretrained clothes-segmentation model (mattmdjaga/segformer_b2_clothes,
# downloaded automatically on first use), which produces a much more accurate
# clothing-agnostic mask than the geometric fallback (`agnostic_method="heuristic"`,
# no extra dependency beyond mediapipe, ~100x faster per image but noticeably
# less accurate - see tryondiffusion/preprocessing.py).
